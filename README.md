# AYZEN — tienda web

Archivos:
- index.html — estructura de la página
- style.css — diseño responsive
- script.js — catálogo, filtros, carrito y WhatsApp
- images/ — carpeta para las fotos reales

IMPORTANTE: los productos y precios del archivo script.js son de ejemplo. Cámbialos antes de publicar.

WhatsApp configurado: 52 461 200 1099.

Para agregar una foto a un producto, coloca el archivo en images/ y cambia, por ejemplo:
image:"images/playera-01.jpg"

La web es estática y se puede publicar en GitHub Pages, Netlify o Vercel.
